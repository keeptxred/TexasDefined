# TexasDefined affiliate portfolio economics

Reviewed 2026-09-25 from current active CJ account terms supplied from the publisher account, TexasDefined first-party referral aggregates, and direct-partner materials where noted.

## Operating rule

Optimize for expected realized revenue **within the same visitor intent**, not for the largest headline percentage across unrelated products.

A higher commission rate is not a reason to replace a relevant product with an unrelated one. A lower-paying partner can also remain preferable when it has materially better conversion, attribution, inventory, or exact-property/product relevance.

Never activate an ordinary advertiser URL merely because the program is approved. Use an account-specific tracked affiliate URL or a verified network deep-link mechanism. CJ Link IDs/AIDs are governance identifiers, not shopper-facing URLs by themselves.

## Replacement rules

1. Replace a lower-paying link only when the higher-paying program satisfies the same visitor job.
2. Prefer exact-property/product links over generic home-page links when both are commissionable.
3. Block any known 0% action/SKU from primary placement.
4. Never use CJ marketing-email wrappers such as `email.cj.com` as shopper-facing affiliate destinations.
5. Do not hand-build advertiser tracking formats from a PID/AID or ordinary destination URL. Use the exact CJ Get Link output or a verified advertiser-supported CJ deep-link mechanism.
6. Preserve first-party click/impression attribution on every commercial CTA.
7. Re-check advertiser terms before a material reroute because commission schedules, coupon rules, booking classes, and attribution windows can change.
8. Use realized downstream commission and reversal data once available; headline percentage is only one input.
9. Specific contextual product/category links beat evergreen links; evergreen links beat no-context generic links; if no governed match exists, show no affiliate CTA.
