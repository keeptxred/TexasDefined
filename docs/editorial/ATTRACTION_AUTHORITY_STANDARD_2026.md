# TexasDefined: sitewide attraction authority standard
Effective October 12, 2026. Applies to every new or materially rebuilt attraction destination.

## Publication acceptance
1. **Identity**: One canonical destination URL, correct operator, city/county/region, coordinates, no closed or duplicate listing in Explore.
2. **Editorial**: Distinct site history, geography, experiences, practical visitor choices, primary facts and short/half-day/long-trip plans. Never reuse filler.
3. **Trip logistics**: Operator-sourced parking, bathrooms, admissions, hours, reservations, accessibility, maps, restrictions and facilities. Mark unverified details explicitly; unknown is not absent.
4. **Maps**: Public pin/route map plus official operator facility/trail map where published. Different entrances/units and wheelchair access must not be conflated.
5. **Imagery**: Subject-specific free-to-reuse photography with photographer, asset URL, license terms and attribution; no generic AI stand-in or unauthorized operator photo.
6. **Cross-links**: Make every indexable primary attraction discoverable from Explore. Add related county, city, category, region, nearby trips and complementary pages where editorially useful; reciprocal links when appropriate.
7. **Monetization**: Show only appropriate, valid tracked affiliate experiences/stays/tickets with clear disclosure, never assume an operator ticket is an affiliate link.
8. **Verification**: Operator controls day-of-trip visitor facts. Review weather- and access-sensitive topics every 30 days; other attractions every 90 days. Source URL reachability is not proof a fact is still correct; never advance verification dates without checking.
9. **QA**: Responsive layout, keyboard/screen-reader access, copyright, image load, official link health, schema/canonicals, source citations, visitor planning and real booking checks before live release.

## Delivered framework
- Typed destination visitor-facility fields and shared parking/bathroom/map section on all canonical destination pages.
- Source-specific starter fact records and separate authority-readiness audit; existing index quality gate remains in place.
- Searchable category-filterable Explore attractions directory without duplicate canonical entity pages.
- Static source-candidate inventory with weekly CI artifact and regression contract. This inventory does not claim a live Supabase census.

## Outstanding before claiming the project finished
- Reconcile static source candidates and source gaps with the entire live Supabase catalog and authoritative external place rosters.
- Verify and fill every destination's onsite parking, restrooms, official map, accessibility, operational facts and history.
- Complete photo license trails, galleries where useful, affiliate tracking validation and editorially appropriate reciprocal links.
- Run final build, accessibility/manual production checks and verify the deployed commit matches the accepted source.

An automatically generated checklist is a measurable remediation backlog, not a claim that unverified attraction pages meet the authority standard.
