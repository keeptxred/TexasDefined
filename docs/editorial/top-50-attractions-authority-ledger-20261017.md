## Release gate for each entry

1. Verify the canonical live destination or route. Preserve any strong existing page; select one URL per user intent and redirect genuine duplicates.
2. Independently research controlling operator sources for tickets, fees, hours, access, parking, reservations, accessibility, safety, current closure status and current experience; add supporting historical/scientific sources.
3. Compare against at least three credible official/independent visitor resources; document the visitor-intent gap, new original value and resolved factual conflicts. Record verified source-check date only after actual review.
4. Produce attraction-specific history, on-the-ground practical visit decisions, who should skip or defer, seasonal hazards, three usable itinerary formats, distinctive visitor FAQs and useful local dining/hotel/side-trip pairings. Museum records additionally require a museum authority dossier, independently researched FAQs with evidence and exhibits/family/dining checks.
5. Audit exact-place images for rights, provenance, captions, alt text and appropriate dimensions. Do not use an unverified photo as if it depicts the attraction.
6. Link both ways to verified city/county pages, existing relevant destinations, historical/contextual guides, nearby stops and source references; check that routes resolve. Link to official ticketing and honest, disclosed affiliate offers only where genuinely useful.
7. Review desktop/mobile a11y, headings, canonical meta, schema reflecting visible facts, sitemap/indexability, performance budgets, broken links and the Supabase fact-verification registry/source coverage.
8. Execute `node scripts/ci/run-premerge-validation.mjs` on the candidate and reconciled heads, respect protected checks, deploy, smoke-test changed public HTML and routes, then review Search Console. Never certify based on a test passing in isolation.

## Non-goals / safeguards

- No automated refreshing of fact-review dates without fact checking.
- No invented exact admissions, schedules, distances, promotions, crowd size or popularity.
- No mass thin pages, orphan pages, site-wide auditing per update or bypass of required checks.
- Do not conflate a historic venue with an event occurrence (for example Texas Renaissance Festival) or a stadium with a scheduled game.
