# Texas Explained question library

`/texas-explained` is the flagship discovery hub for the 10 core Texas Explained guides and their supporting explainers.

`/texas-explained/questions` contains the 140-answer plain-English question library. Keeping the full answer inventory off the flagship hub preserves the authority content while reducing page length, duplication and reader fatigue.

The question library remains a substantive destination rather than creating 140 thin child pages. Deep-dive links continue to point to the existing canonical guides where a subject warrants long-form treatment.
