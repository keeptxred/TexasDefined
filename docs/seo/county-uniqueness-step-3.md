# County Uniqueness — Step 3

Status: implementation in progress.

This workstream reduces template similarity across the 254 Texas county guides without inventing local facts. County-specific framing must be derived from verified U.S. Census Bureau, Texas State Library, local-government, knowledge-graph, and existing editorial data only.

Guardrails:
- Omit unavailable facts rather than fill gaps with generic local color.
- Derived metrics must be mathematically reproducible from cited source fields.
- Do not infer attractions, politics, demographics, culture, costs, growth, or jurisdiction-specific services without a supporting source.
- Preserve the existing canonical county route and property-tax relationships.
- Regression tests must protect source attribution and prevent a return to one repeated county paragraph.
