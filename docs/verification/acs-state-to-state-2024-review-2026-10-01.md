# Census state-to-state migration-flow review — 2024 ACS remains current

Reviewed: 2026-10-01

Primary source: U.S. Census Bureau, *State-to-State Migration Flows*.

Source URL: https://www.census.gov/data/tables/time-series/demo/geographic-mobility/state-to-state-migration.html

Release notice: https://www.census.gov/newsroom/press-releases/2026/2024-state-to-state-migration.html

## Review result

The Census state-to-state migration-flow table repository was rechecked on October 1, 2026. The 2024 State-to-State Migration Flows remain the newest table currently listed; put another way, 2024 remains the newest table currently listed. Census released the 2024 statistics on January 21, 2026, based on the 2024 American Community Survey 1-year estimates.

No newer 2025 state-to-state migration-flow table was listed at review time, so TexasDefined should continue labeling the 2024 ACS flow product as the current state-to-state migration source rather than implying that a 2025 flow table exists.

Re-review after the next annual release window, by February 1, 2027.
