# Census state-to-state migration flows review — 2024 ACS

Reviewed: 2026-10-01

Primary source: U.S. Census Bureau, *State-to-State Migration Flows*.

Source URL: https://www.census.gov/data/tables/time-series/demo/geographic-mobility/state-to-state-migration.html

Release evidence: U.S. Census Bureau, *2024 State-to-State Migration Flows Statistics Now Available*, released January 21, 2026.

Release URL: https://www.census.gov/newsroom/press-releases/2026/2024-state-to-state-migration.html

## Review result

The Census Bureau's current State-to-State Migration Flows table package still lists **2024** as the newest available year. The January 21, 2026 release states that these statistics are based on the **2024 American Community Survey 1-year estimates**.

No newer state-to-state migration-flow table was available in the Census Bureau's current table series when reviewed on October 1, 2026. TexasDefined should therefore continue treating the 2024 ACS state-to-state flow product as the current official release until Census publishes a newer table package.

Re-review during the next annual release window, no later than February 15, 2027.
