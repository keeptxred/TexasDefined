# Historic-site image provenance and reuse review — October 12, 2026

These are **file-specific, independently checked** image rights, not a blanket license for museum collections, Texas Historical Commission photographs, or every Wikimedia Commons file. Images must portray the actual site and may not be marketed as TexasDefined field photography unless created by a TexasDefined contributor.

## Review rules

1. Inspect each file page's actual image license, photographer, date, source and depicted subject; category-level Wikimedia licenses are insufficient.
2. For CC BY-SA files, display/retain the full license and attribution links. If transformations are published, record the transformation and apply relevant share-alike conditions.
3. Use descriptive alt text for the real subject, not generic hero text.
4. Preserve original proportions and avoid false claims of original site buildings where reconstruction has occurred.
5. A single verified hero does **not** satisfy a multiple-image or original field-photography requirement. Additional views require separate file-by-file clearance.
