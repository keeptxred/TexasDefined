# Calhoun County county-series sources

- Texas State Historical Association, *Calhoun County* and *Port Lavaca, TX*.
- Calhoun County Museum, county history and historical-marker references for Linnville, Indianola and Port Lavaca.
- Texas State Library and Archives Commission, county-seat reference.
- Texas Comptroller, Calhoun County appraisal-district and tax-office directory.
- Wikimedia Commons, *Calhoun County Texas Courthouse 2016.jpg*, photographed by Larry D. Moore and licensed CC BY 4.0.
