# TexasDefined

TexasDefined is an independent Texas lifestyle publication covering travel, food, events, history, home and garden, real estate, sports, shopping, and practical guides for living in Texas.

The site is maintained as its own application, with separate branding, navigation, SEO, canonical URLs, content, and deployment configuration.

## Development

You need Node.js and npm. If needed, install Node with [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd TexasDefined
npm i
npm run dev
```

Repository changes are developed and reviewed through GitHub. Preserve the existing production safeguards, validation gates, deployment configuration, and publication boundaries.
