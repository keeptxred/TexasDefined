## Disposition meanings

- `enrich-existing-live-page` — an existing live page already owns substantially the same query/intent; use the draft as source/enrichment material rather than publishing a second URL.
- `covered-by-live-hub` — production already has a strong hub/destination cluster for the subject; decide whether the draft adds a genuinely distinct intent before creating a standalone page.
- `needs-cannibalization-review` — related live coverage exists, but the draft may still justify a distinct page if Search Console/query intent supports it.
- `draft-only-candidate` — no strong same-intent production page was identified in this pass; remains a candidate for later editorial promotion, subject to normal approval/verification.

## Promotion rule after this audit

Before any high-priority draft is promoted:

1. Recheck the current production route inventory.
2. Review current Search Console queries/pages for intent overlap.
3. Prefer enriching the canonical live authority page when intent substantially overlaps.
4. Create a new URL only when it answers a distinct search/user need and has enough unique substance to stand alone.
5. Preserve `status: draft` and `publish_approved: no` until separate explicit approval.
